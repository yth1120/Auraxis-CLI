# @auraxis/cli

终端交互式 Auraxis Agent。

```bash
auraxis
auraxis --run "修复登录 bug" --auto-approve
auraxis --sessions
auraxis --doctor
```

交互模式支持：

- 流式文本 / 思考 / 工具输出
- `ask` / `plan` / `auto` 权限模式
- 交互式危险工具审批
- 计划生成与批准
- `/model` `/mode` `/sandbox` `/sessions` 等斜杠命令
- 四套终端主题：dark / light / neon / mono
- MCP、技能、子 Agent 和 Git 工作流工具
- 会话创建、保存与恢复

CLI 可独立发布，不需要 Auraxis 桌面端。
